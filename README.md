# Student Resource Hub (EduHub)

A comprehensive, one-stop web portal designed to streamline the academic life of college students. EduHub provides easy access to study materials, schedules, important announcements, and essential tools.

## 🚀 Features

- **Academic Resources (Notes)**: Access categorized lecture notes for subjects like Advanced Mathematics, Quantum Physics, Data Structures, and more. Includes a real-time search feature.
- **Weekly Schedule (Timetable)**: Stay organized with a dynamic timetable that automatically highlights the current day of the week.
- **Latest Updates (Announcements)**: Get the latest news on exams, campus events, and academic deadlines.
- **Quick Portals (Important Links)**: Direct access to essential external resources such as the LMS Portal, Exam Portal, and E-Library.
- **Study Tips**: Master your studies with proven techniques like the Pomodoro Technique, Active Recall, and Spaced Repetition.
- **Responsive Design**: Fully optimized for both desktop and mobile devices with a clean, modern UI.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom Variables, Flexbox, Grid), JavaScript (Vanilla ES6+)
- **Icons**: Font Awesome 6.4.0
- **Deployment**: Vercel (Configured for Clean URLs)

## 📁 Project Structure

- `index.html`: Home page with quick access to all modules and motivational quotes.
- `notes.html`: Resource hub for course materials with search functionality.
- `timetable.html`: Interactive weekly class schedule.
- `announcements.html`: Feed for latest college updates and news.
- `links.html`: Collection of important external portal links.
- `tips.html`: Educational guide on effective study habits.
- `css/style.css`: Main stylesheet containing modern UI components and layout.
- `js/script.js`: Core JavaScript for navigation, filtering, and dynamic highlighting.
- `vercel.json`: Deployment configuration for Vercel.

## 🚦 Getting Started

### Local Development

Since this is a static website, you can run it locally without any complex setup:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open `index.html` in your preferred web browser.

### Deployment

This project is ready to be deployed on **Vercel**. Simply connect your repository to Vercel, and it will handle the rest, including the "Clean URLs" configuration specified in `vercel.json`.
